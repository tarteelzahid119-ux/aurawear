# AuraWear 👕✨

A modern full-stack fashion e-commerce web application built with Node.js, Express, and React.

## 🚀 Features

- 🛍️ Product listing with categories
- 🛒 Add to cart functionality
- ⭐ Product reviews & ratings
- 🔐 Admin panel (Add/Delete products)
- 🌙 Dark mode toggle
- 📱 Fully responsive (Mobile friendly)

## 🛠️ Tech Stack

- Backend: Node.js, Express
- Frontend: React (CDN based)
- Authentication: JWT
- Styling: Custom CSS
